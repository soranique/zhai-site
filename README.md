# 神诞斋期版本对照

江南周期性神诞持斋研究的可视化网站：以神明为单位，对照各版本斋期表（《玉匣記》等）的记载，与实践记录、《申报》、风俗志的叙事史料。

页面：

- **概览**：数据规模、斋历版本（按年代）、实践记录最多的神明
- **版本对照**：数据库神明 × 全部斋历版本的矩阵，并列叙事史料条数，可搜索、筛选、排序
- **诸本对照**：「玉匣記及其他斋历：版本横向对比」工作簿中的全部版本，逐条对照：版本目录、神明 × 版本矩阵（标出与多数版本不同的日期）、每位神明在各版本中的原文、每个版本的全部条目；数据在 `editions-data.js`
- **斋期日历**：任选最多 4 个斋历版本，按月排列神诞与斋日，并列实践记录；鼠标移到神名上，同一神在各列一起高亮；有实践记录对上的条目在神名后加绿点（存在偏差为黄点）
- **实践与斋历**：实践记录与斋历条目逐条对上的部分（研究者核定的「贴合」「存在偏差」），可按关系筛选、搜索
- **环形历**：任选一个斋历版本（下拉选单，默认 1827 合安堂本《新增廣玉匣記》），把全部神圣日排成农历年的历盘（十二月 × 三十日），按「编码日期类型」着色，附出处构成（有出处的版本）、十斋日检验与一神多日；网址 `#ring/版本目录编号` 可直接打开某一版本
- **版本线索图**（页面标题「刊刻地与版本线索图」，网址仍为 `#spread`）：《玉匣記》相关本子的刊刻、抄写、购得与收藏地点，以及版本之间的文本关联（共用序文、校者署名或题名）；据工作簿已录版本与三浦國雄 2002 的著录（未目验）。连线不表示已确证的传播路线；版本关联线不画箭头。资料在 `tools/spread/spread_sources.json`，改后运行 `cd tools/spread && npm install && node build_spread.mjs` 重新生成 `spread-data.js`
- **版本亲疏**：已获完整文本的版本按条目内容比较：重合度网络（横轴年代、纵向文本类型）、共有的少数日期、有依据的先后关系、重合度矩阵、道藏本条目的保留，并可任选两本逐条细看（见下）；数据由 `python3 build_kinship.py 玉匣記版本对比.xlsx` 生成 `kinship-data.js`（计入哪些版本、分道、先后关系等设定写在脚本开头）
- **神明档案**：单个神明在各版本中的条目、经典核查、实践记录、《申报》与风俗志；条目与实践记录互相链接（网址 `#g/ZS005/P0070` 直接跳到该神的某条实践记录）
- **缺口**：自动统计的待做事项

各页串联：

- **全站搜索**（页首，按 `/` 键）：汉字（繁简互通）、拼音、记录 ID（P0231、12-0304、W165、ZS001）都能搜；结果按神明、斋历条目、实践记录、文献分组，回车或点击直接跳过去。繁简对照表在 `search-data.js`，由 `build_search.py` 生成。
- **神明聚焦**：在搜索结果或神明档案、诸本对照的神明页点「聚焦此神」，各页只突出这位神：环形历上它的条目亮起、其余变淡；「实践与斋历」的热力图和列表只算它的实践记录；诸本对照把它的行置顶并滚过去；版本线索图标出收录它的版本的相关地点；版本对照、斋期日历、神明列表也会标出。页首横条可取消，选择记在浏览器里。
- **「这一天」面板**：在热力图、环形历（放大某月后点一天）或诸本对照、版本页、神明页里点任意一个日期，都打开同一个面板：左边是各版本这一天的条目（原文照录），右边是对上的实践记录，标出贴合或偏差。可用 ← → 键看前一天、后一天。
- **年代筛选与播放**（「实践与斋历」「版本线索图」页首）：可按晚明（–1643）、清代（1644–1859）、晚清民国（1860–）三段切换，也可拖动起止年自定区间；热力图、按神明列表、「这一天」面板和版本线索图同时只算这段时间的材料，选择全站共用、记在浏览器里。实践记录按段切换时用研究者编码的「时段」，自定起止时用「约略年份」（无年份者不计）；版本线索图按说明里所记的刊刻、抄写、购得年份，三段在地图上暂以 1644、1860 为界。「▶ 按年代播放」从起年开始逐年累积，热力图的格子、地图上的地点与连线逐年出现；可与神明聚焦合用（如聚焦雷祖看雷斋集中在晚清民国）。
- **两本细看**（在「版本亲疏」页：点矩阵里任一格，或点「⇄ 选两个版本逐条细看」；网址 `#kin/甲本编号/乙本编号`，编号即版本目录编号，旧网址 `#cmp/…` 自动转过来）：以浮窗打开，按月日对齐分三栏列出两本共有、只见于甲本、只见于乙本。比较方法与矩阵完全相同（跨几天的条目按日拆开、位置空白者算正文），所以浮窗里的重合度与矩阵格子一致。同一位神同月异日的两条用连线标出，异月的在条目下注明另一本的日期；浮窗里点日期会在上面叠开「这一天」，Esc 逐层关闭，浏览器「后退」也能关掉浮窗。

视觉规则：

- **配色**：朱红只用于强调与数量，如热力图、重合度矩阵、聚焦、链接下划线。分类一律用一套矿物色：石青、青莲、石绿、藤黄、天青、苔绿，外加暖灰（其他）、铅灰（未定）。这套颜色已用色盲模拟检验，深色模式另有一套。颜色定义在 `index.html` 开头的 `--cat1`…`--cat6`，环形历、版本亲疏的文本类型、版本线索图的版本关联、斋期日历的版本栏都从这里取色。新加图表时，分类请用这几种颜色，不要再用红色。
- **字体**：中文一律黑体（苹果设备用苹方，其他设备用思源黑体 Noto Sans SC）；英文、法文和所有数字用苹果系统字体（SF），非苹果设备用外观相近的 Inter；史料原文（斋历条目原文、引文）用楷体（霞鹜文楷 TC；离线时用系统楷体）。拉丁字体排在每组字体的最前面：它们不含汉字，汉字自动落到后面的黑体或楷体（`--font-body`、`--font-src`）。符号（箭头、三角、圈码）由黑体字体统一提供；「复制链接」的图标是线条图形，不用表情字。
- **首页**以默认版本的环形历开场，数字卡片放在下方。

研究与发表用：

- **复制链接**（页首「🔗 复制链接」）：把当前画面写进网址，包括各页的筛选（如热力图的计数单位、只看偏差）、神明聚焦、年代、界面语言、打开的「这一天」或两本细看。发给别人或写进论文注释，对方打开看到的是同一画面。网址形如 `#fit?unit=src&rel=dev&t=1800-1900&focus=ZS005`；「?」后没写的项一律取默认值。读进来以后状态会从地址栏去掉，要重新得到链接就再点一次按钮。
- **下载 CSV**：每张表格右上方有「下载 CSV」，导出当前显示的行（含筛选；诸本对照的大表只导出已显示的部分，需要全部时先点「再显示」）。热力图另有按钮，导出 12 个月 × 30 日的计数。文件名只用英文字母与数字。
- **复制引用**：实践记录、风俗志条目旁的「引用」按钮，以及悬停卡片上的「引用」，会把引用格式复制到剪贴板，如「P0231，《武林舊事》卷三〈中元〉」「12-0346，《書名》（年代），七月十五「原文」」。英文、法文界面写成「P0231, Wulin jiushi 武林舊事, 卷三〈中元〉」。
- **演示模式**（页首「▶ 演示」）：把几个关键画面按顺序串起来，每步一句说明（中英法），底部有翻页条。←／→、PageUp／PageDown、空格都能翻页（翻页笔可用），Esc 退出，「全屏」适合投影。默认步骤在 `demo.js`。在演示条上点「编辑步骤」可改说明、调顺序、删除，「加入当前画面」把页面现在的样子存为新的一步。改动存在本浏览器里；要换一台电脑也能用，点「导出」后把内容贴进 `demo.js`。

细节：

- **悬停卡片**：页面上的神名、规范名、版本名链接，以及文中的记录 ID（P0231、W165、ZS001、H723、12-0304，带虚线下划线），鼠标停留片刻就弹出简要信息：年代、出处、拼音、条数等。卡片上可直接复制引用，不用离开当前页。
- **手机与平板**：悬停提示改成底部的卡片。热力图点一下先看卡片，再点一次或点卡片上的按钮才打开「这一天」；热力图有「－／＋」缩放。环形历点一个月放大，再点一天在旁边的面板里看，面板上有「打开这一天」。记录 ID 点一下出卡片。窄屏上页首不再固定在顶部。窄屏上导航和工具收进「☰」目录。
- **长说明折叠**：页面说明超过三行时只留两行，点「展开说明」看全文；方法上的限定语（如「不等于实际持斋的人数」「未目验」）始终显示，规则写在 `index.html` 的 `LEDE_KEEP`。
- **版本列表头**：版本对照、诸本对照的表头用「版本亲疏」的短名（`build_kinship.py` 的 `SHORT`），鼠标移上去看工作表全名。

页首「中｜EN｜FR」三个按钮切换中文、英文、法文界面，选择会记在浏览器里；网址加 `?lang=en` 或 `?lang=fr` 可直接打开英文版或法文版（如 `https://soranique.github.io/zhai-site/?lang=fr#ring`）。英文版、法文版的规则：

- 人名、神名、地名、书名不翻译，写成「拼音 汉字」，书名拼音为斜体（如 *Yuxiaji* 玉匣記、Guanyin 观音）。拼音由程序自动生成，难免有分词或多音字错误，发现后在 `pinyin_util.py` 的 `FIX` 里补一条再重新生成数据即可。
- 编码取值（证据强度、时段、D/A/C/B 等）给出英文；农历日期写成「月/日」（如 6/24）。
- 研究笔记、摘要、原文引文保持中文。
- 界面文字在 `index.html`、`ring.js` 里以 `L('中文', 'English')` 成对书写；编码的英文在 `i18n.js` 的 `CODES`。
- 法文：固定的字句写在 `fr.js`，是一张「英文 → 法文」对照表；含数字等变量的句子在 `L()` 里写第三个参数，如 `L(n + ' 条', n + ' entries', n + ' entrées')`。新加界面文字时，要么写第三个参数，要么在 `fr.js` 补一行（英文须与源代码一字不差）；两样都没有的，法文界面会显示英文。
- 法文版的日期：农历「月/日」同英文；月份写成「1er mois」「6e mois」，「初八」写成「jour 8」。专有名词、编码取值的规则与英文版相同（编码的法文也在 `fr.js`）。

## 更新数据

持斋研究数据库更新后：

1. 在 Excel 或 WPS 里打开数据库并保存一次（这样公式格子才有值）。
2. 运行：`python3 build_data.py 持斋研究数据库.xlsx --no-quotes`（`--no-quotes` 去掉原文摘录，公开网站用这个）（需要先装：`pip install openpyxl pypinyin opencc-python-reimplemented jieba`；后三个用于英文版的拼音，没装也能运行，只是英文版不显示拼音）。
3. 把新生成的 `data.js` 上传到这个仓库，替换旧文件。

### 数据来源

- **斋历**：只有一个来源，即「玉匣記及其他斋历：版本横向对比」工作簿（加了新版本页、改了条目后重新生成）。版本对照、诸本对照、斋期日历、环形历、神明档案里的斋历部分都读它生成的 `editions-data.js`：

```
python3 build_editions.py 玉匣記版本对比.xlsx
```

- 跨版本对齐用工作簿自己的「建議規範名（對比用）」。
- 与数据库神明 ID 的对应写在工作簿「神明总表」：「斋库神明ID（ZS）」栏是核对过的；空着时用「斋库神明ID（候选·待核）」栏（程序按名称／异名完全相同给出），网站标「待核」。
- **两套神明编号，不要混用**：斋库神明 ID 写作 `ZS###`（如 ZS008 三官；2026-10-29 以前写作 G###，号码不变），是持斋研究数据库「神明」表的 ID，用来连接实践记录与斋历；神明编码写作 `G####`（如 G0303 元始天尊），是研究者自己的神明编码，在神明总表「神明编码（G####）」栏，网站只作显示。
- 实践记录与斋历条目的对应写在数据库「实践记录」表：「对应斋期表条目ID」（工作簿条目ID）、「对应关系」（贴合／存在偏差／存在偏差（无对应条目）／不对应／待查／待确认删除）、「对应说明」。网站只连接有条目ID 的「贴合」与「存在偏差」。
- 「性質」栏（按神填）目前网站未用；填好后环形历可改按道、佛、地方、儒着色。
- 各版本页的「条目ID」栏（版本目录编号＋序号，如 `03-0123`）是固定值，新录入的行要自己补。
- 「神明认定备注」「总表核对」两栏是内部批注，不输出；资料来源含「識典」的版本不输出原文。
- 持斋研究数据库的「斋期表条目」已并入工作簿（報恩論、玉历钞传警世两页；道藏本 1607 工作簿原已有；众喜粗言没有日期，不并入），网站不再读它。

**神明、实践记录、《申报》、风俗志**：来自持斋研究数据库，由 `build_data.py` 生成 `data.js`。

运行完 `build_data.py`、`build_editions.py`、`build_kinship.py` 后，先运行 `python3 apply_traditional.py`（把数据转成繁体；史料原文、照录栏不转，转换规则在 `zh_trad.py`），再运行 `python3 build_search.py`（更新搜索用的繁简对照）。神名合并在工作簿的「建議規範名（對比用）」栏，对照表见工作簿「規範名歸併表」页。改了 `data.js`、`editions-data.js`、`ring.js` 等文件后，再运行 `python3 stamp_versions.py`：它给 `index.html` 里的文件地址加上版本号，读者的浏览器才会取新文件，而不是沿用缓存的旧版。

不会运行程序也没关系：把新的 Excel 交给 Claude，说「更新网站数据」即可。

本仓库不包含 Excel 数据库本身，公开版也不含数据库的原文摘录。「已核对原书」目前全部为「否」：原文摘录多据电子文本或资料库全文，引用前请核原书。
